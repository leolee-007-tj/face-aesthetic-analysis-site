# 面部美学分析 · Face Aesthetic Analysis V1

브라우저 안에서 얼굴 사진을 분석하는 독립 실행형 React/Vite 웹앱입니다. 고객 사진은 서버로 전송하지 않고 현재 브라우저 세션에서만 처리합니다.

## 실행

```bash
pnpm install --ignore-scripts
pnpm dev
```

프로덕션 빌드는 다음과 같습니다.

```bash
./node_modules/.bin/vite build
```

`pnpm install` 환경에서 esbuild의 빌드 스크립트가 정책상 차단될 수 있으므로, 검증 환경에서는 `--ignore-scripts`와 직접 실행 가능한 Vite 바이너리를 사용합니다.

## 구현 범위

사진 업로드, 정면·좌우 15°·좌우 45° 사진 슬롯, 브라우저 내 MediaPipe Face Landmarker 로드 및 검출, SVG overlay, 레이어 ON/OFF, 중국어 관찰 결과, 관찰 문구 편집, 각도별 PNG 저장, 오류 상태 처리를 포함합니다. 각 슬롯에 사진을 따로 넣은 뒤 `分析全部照片`를 누르면 사진마다 독립적으로 landmark를 검출하고 관찰 결과를 계산합니다. `导出全部 PNG`를 누르면 분석이 완료된 각도마다 동일한 원본 픽셀 크기의 얼굴+분석선 합성본, 얼굴 단독본, 투명 분석선본 3개가 다운로드됩니다. 각 결과물은 해당 사진의 landmark와 현재 활성화된 레이어를 공유합니다. 모델과 WASM 리소스는 첫 분석 시 CDN에서 로드되며, 이미지 자체는 외부 서버에 전송하지 않습니다.

## 실제 landmark 기반 기능과 표준 미학 템플릿 기반 기능

| 구분 | 구현 내용 |
|---|---|
| **실제 landmark 기반** | MediaPipe Face Landmarker가 사진에서 얼굴의 478개 landmark를 검출합니다. 얼굴 외곽 reference polyline, 중심선의 상·하단, 코·입·턱 위치, 눈 높이 차이, 얼굴 bounding box, 일부 관심영역 위치, PNG export의 모든 선·면·점 좌표가 검출 landmark에 따라 계산됩니다. 원본 픽셀 크기를 그대로 사용하므로 합성본과 분리본의 크기·좌표가 일치합니다. |
| **landmark에서 계산된 관찰** | 눈 높이 차이, 중안면 중심 위치, 얼굴 전체 높이를 기준으로 한 하안면 상대 길이를 계산해 `不明显 / 轻微 / 较明显` 관찰 강도로 표현합니다. 이는 미적 관찰 참고이며 진단이 아닙니다. |
| **표준 미학 템플릿 기반** | `三庭`의 두 기준선, `高光面 / 灰面 / 阴影面`의 반투명 polygon 구성, OG-line의 곡선 형태, 관심영역 ellipse, 라벨의 문구와 배치는 landmark에 맞춰 변형되는 상담용 시각화 템플릿입니다. 사진의 실제 조명이나 조직을 과학적으로 측정하지 않습니다. |
| **안전 문구** | 의료 진단, 결함 판정, 제품·용량·치료 처방을 포함하지 않으며, 결과 패널에 상담 참고용 고지문을 표시합니다. |

## 주요 파일

`src/main.tsx`에 업로드·검출·분석 계산·SVG 오버레이·레이어 상태·PNG export가 있으며, `src/styles.css`에 프리미엄 미니멀 UI와 iPad/모바일 반응형 규칙이 있습니다.

## 현재의 제한

사진 각도는 현재 사용자가 각도별 슬롯에 직접 배정합니다. 자동 pose 추정과 control point 드래그 편집은 다음 단계의 확장 대상입니다. HEIC/HEIF는 브라우저 안에서 JPEG로 변환한 뒤 분석하며, 저장 시에는 각 각도의 얼굴 단독, 투명 분석선, 합성 결과가 모두 동일한 원본 픽셀 크기로 생성됩니다.

> 이 애플리케이션의 모든 출력은 미학 상담 참고용이며 의료 진단 또는 치료 권고가 아닙니다. 실제 상담과 시술 판단은 자격을 갖춘 의료 전문가의 평가를 따라야 합니다.
